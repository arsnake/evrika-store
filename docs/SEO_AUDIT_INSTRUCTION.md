## БЛОК 1 — ТЕХНИЧЕСКИЙ ФУНДАМЕНТ

### 1.1 Индексация и crawlability

**Проверить и исправить:**

```
□ robots.txt — корректные директивы для OcStore:
  User-agent: *
  Disallow: /admin/
  Disallow: /index.php?route=account/
  Disallow: /index.php?route=checkout/
  Disallow: /index.php?route=product/compare
  Disallow: /index.php?route=product/search
  Disallow: /*?sort=
  Disallow: /*?order=
  Disallow: /*?limit=
  Disallow: /*?filter_
  Sitemap: https://домен/sitemap.xml

□ sitemap.xml — генерация через OcStore:
  - Модуль XML Sitemap включён и настроен
  - Включены: категории, товары, информационные страницы
  - Исключены: служебные страницы (корзина, кабинет, поиск)
  - Обновление: автоматическое при изменении контента
  - Отправить в Яндекс.Вебмастер и Google Search Console

□ Канонические URL:
  - rel="canonical" на каждой странице
  - Страницы с ?sort=, ?limit=, ?order= — canonical на базовый URL
  - Страницы пагинации (/page=2) — canonical на первую страницу
    ИЛИ rel="next"/"prev" (для Google устарело, для Яндекс актуально)

□ Дублированный контент в OcStore — типичные проблемы:
  - /index.php?route=product/category&path=XX дублирует /категория/
  - Товар доступен из нескольких категорий — нужен canonical
  - Страницы с параметрами фильтрации — закрыть в robots.txt
  - Пагинация: /page=1 дублирует базовую страницу
```

**OcStore-специфика — настройки для SEO:**
```
System → Settings → Server:
□ Use SEO URLs: Yes
□ Compression Level: 0 (сжатие отдай nginx/apache)

System → Settings → Store:
□ Meta Title — название магазина для шаблонов
□ Meta Description — описание магазина
```

## БЛОК 2 — АРХИТЕКТУРА URL

**Требования к URL в OcStore с SEO URL включёнными:**

```
✅ Правильно:
/kanctovar/ruchki-gelevye/                     — категория
/kanctovar/ruchki-gelevye/ruchka-berlingo/     — товар
/o-kompanii/                                   — инфо-страница
/brands/berlingo/                              — бренд

❌ Проблемы которые нужно исправить:
/index.php?route=product/category&path=59      — нет ЧПУ
/кириллица-в-url/                              — кириллица (хуже для шаринга)
/category-name_59/                             — ID в URL
/very-long-category-name-that-is-too-long/slug/ — слишком длинный URL
```

**Настройка SEO-псевдонимов в OcStore:**
```
Catalog → Categories → [категория] → SEO → Keyword
Catalog → Products  → [товар]     → SEO → Keyword
```

**Правила именования псевдонимов:**
```
□ Только строчные латинские буквы, цифры, дефис
□ Никаких подчёркиваний (дефис = разделитель слов для поисковиков)
□ Ключевое слово в URL — первые 60 символов
□ Максимальная глубина: 3 уровня (/l1/l2/l3/)
□ Транслитерация по правилам Яндекс (а→a, б→b, в→v...)
```

### 3.1 Шаблоны авто-генерации (для OcStore)

Для большого каталога вручную не заполнить. Создай шаблоны через OCMod или языковые файлы.

**Категория:**
```
Title:       {Название категории} купить оптом в Мелитополе | Эврика
             Максимум: 60 символов

Description: {Название категории} оптом — {кол-во} товаров. Berlingo,
             ГАММА, СТАММ и другие бренды. Доставка по региону. Цены
             для юрлиц и ИП. Звоните: {телефон}
             Максимум: 155–160 символов
```

**Товар:**
```
Title:       {Название товара} — купить оптом | Эврика
             Или: {Название} {Бренд} арт.{артикул} — оптом в Мелитополе

Description: Купите {название товара} оптом. Бренд: {бренд}. Артикул:
             {артикул}. {Краткая характеристика}. Актуальные цены для
             юрлиц — авторизуйтесь или позвоните: {телефон}
```

**Главная:**
```
Title:       Канцелярские товары оптом в Мелитополе — Эврика

Description: Интернет-магазин канцелярии оптом «Эврика». Berlingo,
             ГАММА, СТАММ, Brauberg и другие бренды. Более 20 000
             наименований. Доставка по региону. Персональные цены
             для юрлиц и ИП.
```

### 3.2 Правила для мета-тегов

```
□ Title уникален для каждой страницы
□ Title содержит главный ключевой запрос ближе к началу
□ Description содержит CTA (купить, заказать, позвонить)
□ Description не дублирует Title
□ Нет мета keywords (игнорируется, но засоряет код)
□ og:title, og:description, og:image для соцсетей
□ Страницы пагинации (/page=2...): уникальный title с номером страницы
  Пример: "Ручки гелевые оптом — страница 2 | Эврика"
```

## БЛОК 4 — ЗАГОЛОВКИ И СТРУКТУРА КОНТЕНТА

### 4.1 Иерархия заголовков

```
H1 — один на странице, содержит главный ключ
H2 — подразделы страницы (подкатегории, секции)
H3 — элементы внутри подразделов
H4-H6 — вспомогательные (редко нужны)
```

**По типам страниц:**

```
Главная:
  H1: "Канцелярские товары оптом" (или название магазина)
  H2: "Популярные разделы", "Новые поступления", "Популярные товары"

Категория (Вид A — разделы):
  H1: Точное название категории ("Письменные товары")
  H2: Названия подкатегорий ("Карандаши", "Ручки", "Маркеры")

Категория (Вид Б — товары):
  H1: Название категории с ключом ("Карандаши вечные оптом")
  (Названия товаров — через <a>, не H2/H3)

Товар:
  H1: Полное название товара
  H2: "Характеристики", "Описание", "Похожие товары"

Информационная:
  H1: Точный заголовок страницы
  H2, H3: Логическая структура текста
```

### 4.2 Текст в категориях

```
□ SEO-текст внизу страницы категории: 300–800 слов
□ Естественное вхождение ключей: 1–2% плотность
□ Структура: 2–3 абзаца + маркированный список преимуществ
□ Упоминание: бренды, регион (Мелитополь), тип клиента (оптом, юрлицам)
□ Не закрывать текст под спойлер — поисковик видит, пользователь нет
□ Обновлять раз в 6–12 месяцев
```

```

□ В подвале: ссылки на ключевые категории каталога

```

<a href="/ruchki/">здесь</a>

<a href="/ruchki/">подробнее</a>

✅ Хорошо:

<a href="/karandashi/">карандаши Berlingo</a>

```twig
{# Обязательны на всех страницах кроме главной #}

{# Ссылка на каждый уровень иерархии, кроме текущей страницы #}

## БЛОК 7 — ЛОКАЛЬНОЕ SEO

### 7.1 Региональная оптимизация (Мелитополь)

```
□ Упоминание города в:
  - Title главной страницы
  - H1 или первом абзаце главной страницы
  - Meta description главной
  - Странице "О компании"
  - Странице "Доставка и оплата"
  - Footer (адрес с полным написанием)

□ Страница контактов:
  - Полный адрес с индексом
  - Телефон в формате +7 XXX XXX-XX-XX
  - Карта (Яндекс.Карты или Google Maps iframe)
  - Схема проезда или описание

□ Регистрация в геосервисах:
  - Яндекс.Бизнес (обязательно — влияет на ранжирование в Яндексе)
  - Google Business Profile
  - 2GIS
  - Данные должны совпадать с данными на сайте (NAP-consistency)
```

### 7.2 NAP-consistency (Name, Address, Phone)

```
Единый формат во всех упоминаниях на сайте и в геосервисах:

Название:  Эврика
Адрес:     г. Мелитополь, ул. [название], д. [номер]
Телефон:   +7 (XXX) XXX-XX-XX
Сайт:      https://домен/

Проверить: topbar, footer, страница контактов,
           Schema.org LocalBusiness, Яндекс.Бизнес, Google Business
```

## БЛОК 8 — КОММЕРЧЕСКИЕ ФАКТОРЫ РАНЖИРОВАНИЯ

Яндекс активно учитывает коммерческие факторы. Для B2B особенно важны:

### 8.1 Чеклист коммерческих факторов

```
ДОВЕРИЕ:
□ Страница "О компании" с реальным контентом (не заглушка)
□ Фотографии склада, команды, офиса
□ Реквизиты компании (ИНН, ОГРН — для юрлиц это важно)
□ Сертификаты, лицензии, грамоты (если есть)
□ Отзывы клиентов (реальные, с именами и компаниями)

## ⚠️ ОГРАНИЧЕНИЯ И ПРАВИЛА

### Нельзя:

```
❌ Использовать переспам ключевых слов (плотность > 3%)
❌ Скрывать текст (display:none, белый на белом)
❌ Дублировать мета-теги между страницами
❌ Генерировать бессмысленный контент через ИИ без проверки
❌ Покупать ссылки (риск санкций Яндекс Минусинск)
❌ Создавать дорвеи или страницы только под ключи
❌ Закрывать важный контент от индексации без причины
❌ Ставить noindex на страницы с ценностным контентом
❌ Редиректить несуществующие страницы на главную (только 404)
```

### Обязательно:

```
✅ Каждое изменение логировать (что изменено, когда, зачем)
✅ Перед закрытием страниц в robots.txt — проверить в GSC что они
   не приносят трафик
✅ A/B тестировать изменения мета-тегов на группах страниц
✅ После технических изменений — запрашивать переобход в GSC/Вебмастер
✅ Все тексты проверять на уникальность (Текст.ру или Advego)
✅ Schema.org разметку валидировать перед деплоем
✅ Изменения в robots.txt проверять в Яндекс.Вебмастер → Анализ robots.txt
```
