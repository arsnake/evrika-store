# ТЗ для SEO-специалиста — продакшен
### Проект: «Эврика», канцелярские товары оптом, Мелитополь
### Платформа: OcStore (OpenCart 3)
### Документ передаётся после деплоя сайта на боевой сервер

---

> Технические правки (Schema.org, canonical, шаблоны title) выполнены разработчиком.
> Этот документ — задачи которые требуют экспертизы SEO-специалиста и работы с контентом.

---

## Раздел 1 — Первичная настройка (делать сразу после деплоя)

### 1.1 Зарегистрировать сайт в поисковых системах 🔴

**Яндекс.Вебмастер** (https://webmaster.yandex.ru)
- [ ] Добавить сайт, подтвердить владение (HTML-файл или мета-тег)
- [ ] Загрузить sitemap.xml
- [ ] Настроить регион: Мелитополь → Запорожская область
- [ ] Включить уведомления об ошибках

**Google Search Console** (https://search.google.com/search-console)
- [ ] Добавить ресурс, подтвердить (DNS или HTML-файл)
- [ ] Загрузить sitemap.xml
- [ ] Включить мониторинг Core Web Vitals

**Инструкция по sitemap:**
После деплоя в OcStore: Extensions → Extensions → Feeds → Google Sitemap → Install → Edit → включить, сохранить.
Затем раскомментировать строку в `robots.txt`:
```
Sitemap: https://ВАШ-ДОМЕН/index.php?route=extension/feed/google_sitemap
```

### 1.2 Зарегистрировать в геосервисах 🔴

**Яндекс.Бизнес** (https://business.yandex.ru) — критично для локального SEO
- [ ] Создать карточку организации
- [ ] Заполнить: название, адрес, телефон, сайт, категория, режим работы
- [ ] Загрузить фотографии (офис, склад, товары)
- [ ] Убедиться что данные совпадают с сайтом (NAP-consistency — см. ниже)

**Google Business Profile** (https://business.google.com)
- [ ] Создать / подтвердить карточку
- [ ] Заполнить те же данные что в Яндекс.Бизнес (идентичные!)

**2GIS** (https://2gis.ru/info/advertise)
- [ ] Добавить организацию
- [ ] Данные — идентичные Яндекс.Бизнес

**NAP-consistency — единый формат на всех платформах:**
```
Название:  Эврика
Адрес:     г. Мелитополь, ул. [улица], д. [номер]
Телефон:   +7 (XXX) XXX-XX-XX  (один формат везде!)
Сайт:      https://[домен]/     (с https, без www, со слешем)
```
Проверить что эти данные совпадают в: топбаре сайта, подвале, странице контактов,
Schema.org (файл header.twig — заполнить после деплоя), Яндекс.Бизнес, Google Business.

### 1.3 Настроить SEO-URL для всех категорий и товаров 🔴

OcStore: **Catalog → Categories → [категория] → вкладка "Дизайн" → SEO Keyword**

**Правила формирования slug:**
- Только строчные латинские буквы, цифры, дефис
- Не подчёркивание (`ruchki-gelevye`, не `ruchki_gelevye`)
- Транслитерация по Яндексу: ручки → ruchki, карандаши → karandashi
- Максимум 60 символов
- Ключевое слово — в начале

**Примеры slugs для типичных категорий:**
```
Письменные товары       → pismenye-tovary
Ручки                   → ruchki
Ручки гелевые           → ruchki-gelevye
Карандаши               → karandashi
Тетради                 → tetradi
Папки и файлы           → papki-i-fajly
Краски и кисти          → kraski-i-kisti
Клей и ножницы          → klej-i-nozhnicy
```

**Для товаров:** Catalog → Products → [товар] → вкладка "SEO" → SEO Keyword
```
Ручка гелевая Berlingo Silk Touch → ruchka-gelevaya-berlingo-silk-touch
Тетрадь 48 листов клетка          → tetrad-48-listov-kletka
```

## Раздел 2 — Мета-теги и заголовки

### 2.1 Настроить мета-теги для всех страниц 🔴

Разработчик создал шаблоны авто-генерации (OCMod). Они сработают автоматически
если в карточке не заполнено вручную. Для топ-страниц — заполнить вручную.

**Алгоритм приоритетов:**
1. Если в карточке товара/категории заполнен Meta Title → используется он
2. Если нет → авто-шаблон: `{Название} купить оптом в Мелитополе | Эврика`

**Вручную заполнить для топ-20 категорий и топ-50 товаров:**

Категория:
```
OcStore: Catalog → Categories → [категория] → вкладка "Данные"
  Meta Tag Title:       Ручки гелевые купить оптом в Мелитополе | Эврика
  Meta Tag Description: Гелевые ручки оптом — 120 наименований. Berlingo,
                        СТАММ, GAMMA и другие бренды. Доставка по региону.
                        Цены для юрлиц и ИП. Тел.: +7 (XXX) XXX-XX-XX
```

Товар:
```
OcStore: Catalog → Products → [товар] → вкладка "Данные"
  Meta Tag Title:       Ручка гелевая Berlingo Silk Touch синяя — оптом | Эврика
  Meta Tag Description: Гелевая ручка Berlingo Silk Touch арт. CGp_50126.
                        Синяя, 0.5 мм, резиновый грип. Оптовые цены для
                        юрлиц — авторизуйтесь или звоните: +7 (XXX) XXX-XX-XX
```

**Правила:**
- Title: до 60 символов, главный ключ — в начале
- Description: 140–155 символов, обязательно CTA (купить, позвонить, заказать)
- Description не повторяет Title дословно
- Регион «в Мелитополе» — в title категорий (не товаров)

## Раздел 3 — Контент

### 3.1 SEO-тексты для категорий 🟡

**Где добавлять:** Catalog → Categories → [категория] → поле «Описание»

Текст выводится внизу страницы. НЕ закрывать за спойлером.

**Структура текста (300–500 слов на категорию):**
```
Абзац 1: Что это за товары, для кого, почему это важно.
         Упомянуть бренды, регион, тип клиента.
         Пример: «Гелевые ручки оптом для магазинов, школ и офисов
         Мелитополя и региона. В каталоге — ручки Berlingo, СТАММ, GAMMA...»

Абзац 2: Преимущества покупки у «Эврики».
         Упомянуть: ассортимент, условия оптовой поставки, доставку.

Маркированный список: 3–5 пунктов с LSI-ключами.
         • Ручки шариковые и гелевые от 1 упаковки
         • Сертифицированная продукция, гарантия подлинности
         • Оплата по безналу, НДС, договор поставки

Абзац 3 (необязательно): Как сделать заказ, CTA.
```

**Приоритет категорий для написания текстов:**
1. Категории 1-го уровня (Письменные товары, Бумага, Папки и т.д.)
2. Топ-5 категорий по ассортименту
3. Оставшиеся категории — постепенно

**Плотность ключей:** 1–2%. Никаких списков ключей подряд (Баден-Баден).

---

### 3.2 Описания товаров 🟡

**Минимум для каждого товара:** 50–100 слов

**Шаблон описания:**
```
[Название товара] — [краткая характеристика: тип, материал, цвет, размер].
Подходит для [целевая аудитория: школьников/офиса/художников].
[Бренд] — [1-2 предложения о производителе].
Товар сертифицирован, соответствует ГОСТ [номер если есть].
Минимальная партия: [X] штук/упаковок.
```

**Для одинаковых товаров с разными артикулами** (например ручки одной серии но разных цветов):
использовать шаблонный текст с автоподстановкой цвета/объёма — это допустимо,
если добавить 1–2 уникальных предложения на каждую карточку.

---

### 3.3 Alt-теги для изображений товаров 🟡

OcStore: Catalog → Products → [товар] → вкладка "Изображения" → поле "Image title/alt"

Формат: `[Название товара] [бренд] арт.[артикул]`
```
Ручка гелевая Berlingo Silk Touch синяя 0.5мм арт.CGp_50126
Тетрадь 48 листов клетка СТАММ А5 обложка пластик
```

Не использовать: «изображение», «фото», «картинка», номера типа «img_001».

## Раздел 4 — Страницы доверия и коммерческих факторов

### 4.1 Страница «О компании» 🟡

OcStore: **Catalog → Information → О компании**

**Минимальный контент (влияет на ранжирование Яндекс!):**

```markdown
## О компании «Эврика»

Текст: история, год основания, чем занимаемся, для кого работаем.
Упомянуть: Мелитополь, оптовые поставки, B2B-клиенты.

Раздел «Наши преимущества»: 5–7 пунктов с реальными фактами
(не «качественные товары», а «склад 3 000 м² в Мелитополе»)

Раздел «Как мы работаем»: схема работы с оптовым клиентом

Реквизиты: ИНН, ОГРН, юридический адрес (важно для B2B-доверия)

Фотографии: склад, команда, офис — хотя бы 3–5 фото
```

---

### 4.2 Страница «Доставка и оплата» 🟡

**Обязательные разделы:**

```
1. Способы доставки
   - Самовывоз из Мелитополя (адрес, режим работы)
   - Доставка по городу (условия, стоимость/бесплатно от суммы)
   - Доставка по региону (транспортные компании, сроки, стоимость)
   - Доставка в другие регионы (если есть)

2. Способы оплаты
   - Наличные при самовывозе
   - Безналичный расчёт (для юрлиц: счёт-фактура, НДС — обязательно!)
   - Перевод на карту (если есть)

3. Условия для юридических лиц
   - Договор поставки
   - Отсрочка платежа (если предусмотрена)
   - Документы: счёт, ТОРГ-12, счёт-фактура, УПД

4. Минимальный заказ
   - Минимальная сумма или количество (если есть)

5. Возврат и обмен
   - Условия возврата (кратко, ссылка на законодательство)
```

---

### 4.3 Страница контактов — обязательные элементы 🟡

```

- Телефон кликабелен (уже реализовано в теме)
```
