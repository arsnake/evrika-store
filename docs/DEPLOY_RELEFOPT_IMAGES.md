# Деплой: модуль «РельефОпт — Парсер изображений»

## Назначение

Модуль добавляет панель поиска и загрузки изображений прямо во вкладку **Изображения** редактора товара в админке. Администратор вводит артикул — модуль находит товар на relefopt.ru через API, показывает все фотографии, и одним кликом прикрепляет их к товару.

---

## Файлы для копирования на сервер

### 1. Контроллер

```
public/admin/controller/extension/module/relefopt_images.php
```

Маршруты:
- `GET  index.php?route=extension/module/relefopt_images` — страница настроек
- `POST index.php?route=extension/module/relefopt_images/search` — AJAX-поиск товаров
- `POST index.php?route=extension/module/relefopt_images/importImage` — AJAX-загрузка одного фото

### 2. Модель

```
public/admin/model/extension/module/relefopt_images.php
```

### 3. Шаблон настроек

```
public/admin/view/template/extension/module/relefopt_images.twig
```

### 4. OCMod-патч (инъекция JS в форму товара)

```
ocmod/evrika_relefopt_images.ocmod.zip   ← устанавливать через админку
ocmod/evrika_relefopt_images.ocmod.xml   ← исходник (для контроля)
public/system/evrika_relefopt_images.ocmod.xml  ← для developer-mode
```

## Пошаговый деплой

### Шаг 1 — Скопировать PHP-файлы

Загрузить на сервер три файла (пути относительно корня сайта):

```
admin/controller/extension/module/relefopt_images.php
admin/model/extension/module/relefopt_images.php
admin/view/template/extension/module/relefopt_images.twig
```

### Шаг 2 — Установить OCMod

1. Зайти в админку → **Extensions → Modifications**
2. Нажать кнопку **Upload** (стрелка вверх, правый верхний угол)
3. Выбрать файл: `ocmod/evrika_relefopt_images.ocmod.zip`
4. После загрузки — нажать кнопку **Refresh** (синяя, правый верхний угол)

> Если на сервере включён developer mode — дополнительно скопировать
> `public/system/evrika_relefopt_images.ocmod.xml` в `system/` на сервере.

### Шаг 3 — Очистить кеш шаблонов

В админке: **Dashboard → шестерёнка (Settings) → Refresh** (голубая кнопка).

Либо вручную удалить содержимое папки `system/storage/cache/template/` на сервере.

### Шаг 4 — Настроить Bearer-токен

1. Открыть в браузере: `https://ВАШ_САЙТ/admin/index.php?route=extension/module/relefopt_images&user_token=...`
   (или через меню: **Extensions → Modules → РельефОпт Парсер изображений**)
2. Вставить Bearer-токен в поле **Bearer Token**
3. Нажать **Сохранить настройки**

#### Как получить токен

1. Открыть [relefopt.ru](https://relefopt.ru) и войти в аккаунт
2. Нажать **F12** → вкладка **Network**
3. Выполнить любой поиск на сайте
4. Найти запрос к `/v3/` (например `/v3/catalog/main/search/...`)
5. В заголовках запроса (Request Headers) найти `Authorization: Bearer <ТОКЕН>`
6. Скопировать всё что после `Bearer ` (без слова Bearer)

> Токен — JWT, действует ограниченное время. Если поиск перестал работать — обновить токен по той же инструкции.

#### Автообновление токена (опционально)

Если известны `client_id` и `client_secret` от OAuth-приложения relefopt.ru — заполнить соответствующие поля. Модуль будет автоматически получать новый токен через `client_credentials` при истечении текущего.

## Проверка после деплоя

1. Открыть любой товар в админке → вкладка **Изображения**
2. Внизу вкладки должна появиться панель **«Поиск изображений на РельефОпт»**
3. Убедиться что отображается артикул товара (берётся из поля «Артикул» на вкладке «Данные»)
4. Нажать **Найти изображения** — должны появиться карточки с фото
5. Нажать **Прикрепить все** — фото загружаются последовательно в `catalog/relefopt/`
6. Главное фото (первое) устанавливается в основное изображение товара
7. Остальные добавляются в галерею
8. Нажать **Сохранить** товар

---

## Где хранятся скачанные изображения

```
image/catalog/relefopt/rp_<md5_url>.<ext>
```

Папка создаётся автоматически при первой загрузке. Файлы не удаляются при смене товара — это кеш, используемый повторно при следующем импорте того же фото.

## Возможные ошибки

| Сообщение | Причина | Решение |
|---|---|---|
| Токен не настроен или просрочен | Токен не введён или истёк | Обновить токен в настройках модуля |
| Ошибка авторизации: токен недействителен | Неверный токен | Получить новый токен из DevTools |
| Товар не найден на РельефОпт | Артикул не совпадает | Проверить поле «Артикул» в карточке товара |
| Не удалось создать папку | Нет прав на запись | Дать права `755` на папку `image/catalog/` |
| Ошибка загрузки (HTTP 403) | relefopt.ru блокирует запрос | Проверить токен, возможно нужна авторизация |
